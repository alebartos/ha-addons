# ha-addons

Repository di add-on per Home Assistant.

Aggiungi in Home Assistant: Impostazioni → Add-on → Store → ⋮ → Repository →
`https://github.com/alebartos/ha-addons`

| Add-on | Descrizione |
|---|---|
| [Authelia](authelia/) | Authelia SSO, immagine ufficiale, versione aggiornata ogni giorno da GitHub Actions |
